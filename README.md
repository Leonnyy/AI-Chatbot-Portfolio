# AI Chatbot for Portfolio

This is a **demo AI Chatbot project** for my portfolio. It is built with **Python** and **Gradio** for a simple graphical interface.  

The demo does **not use a live API**; responses are **pre-prepared** for screenshots and portfolio purposes.

## Functionality

- The user types a question into the chatbox.  
- The chatbot returns **pre-prepared demo responses** based on the question.  
- Example responses are defined in the code.

### Example Questions

- What is the capital of France?  
- Explain the Pythagorean Theorem.  
- Give a tip for time management.  
- How does artificial intelligence work?

## How to Use

1. Make sure you have **Python 3** and the **Gradio** library installed.  
2. Open the terminal in the project folder.  
3. Run the script:
